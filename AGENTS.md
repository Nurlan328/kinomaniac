# AGENTS.md

Правила для ИИ-агента (и человека), который меняет этот репозиторий.

## Порядок работы

1. Новое поведение сначала описывается требованием в `SPEC.md` (формат EARS, номер `Bn`).
2. Затем тест в `tests/` со ссылкой на номер требования. Тест работает с заглушкой вместо клиента, без сети и ключа.
3. Затем код. Коммит с кодом не раньше коммита с требованием и тестом.
4. Перед коммитом проходят `uv run pytest` и проверка ключей: их запускает хук pre-commit. Хук не обходится через `--no-verify`.

## Команды

```sh
uv sync --locked                    # окружение
uv run pytest                       # тесты, без ключа
uv run kino.py "запрос"             # один подбор
uv run check.py --provider anthropic --runs 5   # прогоны набора
uv run check.py --report --stable 5             # доля прошедших во всех пяти
uv run bot.py --provider anthropic  # Telegram-бот, нужен TELEGRAM_BOT_TOKEN
uv run bot.py --local               # бот на qwen3.5:4b через Ollama, без ключа
```

## Контракт, который нельзя ломать

Его проверяет автопроверка курса (`check/kino_check.py`):

- `kino.py` при импорте ничего не запускает.
- `pick(client, model, query, films)` возвращает `(outcome, ids)`, печатает показанные фильмы сама, данные берёт из переданного каталога, `films.json` не читает. При любом исходе, кроме `ok`, `ids` пустой.
- Вызов модели через `client.chat.completions.parse(..., response_format=Схема)`.
- Схема выбора: `status`, `reason`, `picks` с `film_id` и `why`; `status` принимает `ok`, `no_match`, `clarify`.
- Каждый вызов модели пишется строкой в `calls.jsonl` с `model`, `request`, `outcome`; при `invalid` поле `rejected`.
- `candidates(query, films, k=30)` без языковой модели; `pick_big` отдаёт модели только кандидатов.

## Запрещено

- Ключи API в коде, в `.env.example`, в журнале и в истории git. Ключи только в `.env`.
- Год, длительность, страны и языки фильмов из памяти модели: только из источника.
- Числа в README не из настоящего запуска.
- Показывать пользователю фильм, которого нет в каталоге, или фильм, нарушающий условие запроса.

## Стиль

- Python 3.12, зависимости через uv.
- Комментарии, docstring, сообщения пользователю по-русски; коммиты по-английски.
- Проверки делает код, а не только промпт.
