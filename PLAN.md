# План уровня Legendary

Порядок шагов соответствует истории коммитов: требования и тесты появляются раньше кода.

1. **Процесс.** `SPEC.md` (требования B1–B17 в EARS), `AGENTS.md`, этот план, хук pre-commit (pytest и проверка ключей), CI на GitHub Actions с pytest и заглушкой вместо модели.
2. **Тесты.** `tests/test_bot.py`: уточнение (B5–B7), «ещё» без повторов (B8–B10), исключения до конца диалога (B11–B13), сброс и ошибки (B14–B16), доля стабильно пройденных (B17). Пока `bot.py` нет, тесты пропускаются через `pytest.importorskip`, чтобы хук не блокировал коммит.
3. **Код.**
   - `kino.py`: статус `clarify` в схеме `Choice`, правило в промпте, исход `clarify` в `pick`.
   - `bot.py`: класс `Dialog` без зависимости от Telegram (вся логика диалога, тестируется заглушкой) и тонкий слой Telegram Bot API на long polling.
   - `check.py`: `--stable N` в отчёте.
4. **Надёжность.** Пять прогонов `queries.json` на `claude-haiku-5-5` с итоговым кодом; в README доля запросов, прошедших во всех пяти, рядом с долей в одном прогоне.
5. **Путь за $0.** Бот на локальной `qwen3.5:4b` через Ollama; честная заметка о качестве и скорости в README.
6. **Видео** до двух минут: бот отвечает на телефоне, ссылка в README.
